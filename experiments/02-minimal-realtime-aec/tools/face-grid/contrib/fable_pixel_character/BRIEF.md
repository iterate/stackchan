# Pixel and adventure-game worker

Research and prototype a wide set of original pixel-art talking portraits
informed by 1980s/1990s EGA/VGA adventure games, LucasArts-style talkie
portraits, Sierra quest portraits, JRPG dialogue boxes, and modern deliberate
pixel art. Include multiple sprite-mouth systems and palette/dither strategies.
Do not reproduce copyrighted characters or artwork.

Create standalone portable C, tests, a renderer manifest, and a concise
source/licensing research report in this directory only. Input/output and
performance constraints are in `../README.md`.
