# Robot-face and eye-motion worker

Research and prototype original procedural robot faces informed by Anki
Vector/Cozmo parameterized eyes, FluxGarage RoboEyes, m5stack-avatar/Stack-chan,
EVE-like minimal displays, Uncanny Eyes, virtual pets, and social-robot eye
animation research. Emphasize blinks, micro/macro saccades, gaze holds,
eyebrows, lid anticipation, asymmetric motion, and idle acts.

Do not copy GPL code or copyrighted art. Create standalone portable C, tests, a
renderer manifest, and a source/licensing research report in this directory
only. Input/output and performance constraints are in `../README.md`.
