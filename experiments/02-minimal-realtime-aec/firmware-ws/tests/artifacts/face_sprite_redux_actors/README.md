# Sprite Redux actor audit artifacts

Generated by:

```sh
firmware-ws/tests/run_face_sprite_redux_actors_native.sh \
  firmware-ws/tests/artifacts/face_sprite_redux_actors
```

The six combined sheets are unlabeled renderer output. Rows, top to bottom,
are legacy IDs 58, 59 and 60.

- expression sheets: 11 columns, neutral through embarrassed;
- viseme sheets: 15 columns in OVR15 enum order;
- temporal sheets: 16 chronological columns, with two anticipation frames,
  twelve active frames and two settle frames;
- `native` sheets: exact 160×120 renderer tiles;
- `exact-40x30` sheets: center-sampled integer reduction with no smoothing.

`sanitizer-test.txt`, `wasm-test.txt`, `code-size.txt` and `benchmark.txt` are
retained from the same run. Benchmark numbers are host-specific; the pass/fail
contracts and rendered pixels are deterministic.
