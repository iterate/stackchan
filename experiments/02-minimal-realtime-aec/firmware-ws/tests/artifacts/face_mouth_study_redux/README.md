# Face mouth study redux artifacts

These sheets are generated by
`../../run_face_mouth_study_redux_native.sh` from the standalone legacy
23–28 mouth study.

- `mouth-study-expressions-6x11`: six rigs by eleven authored emotions.
- `mouth-study-temporal-speech-6x24`: chronological
  rest → anticipation → active coarticulation → settle → release.
- `mouth-study-vocabularies-6x29`: OVR15, VRM5, and Preston9 shapes.

Both PPM sources and PNG inspection copies are retained. Every rendered tile
is the original 160×120 RGB565 frame; only the 12-pixel label band is added by
the dump tool.

beat, four-frame held phoneme sections, three eased settle frames, and a
release frame. Both PPM sources and PNG inspection copies are retained for
the regenerated sheets; the two `before-second-pass` files are PNG snapshots.
