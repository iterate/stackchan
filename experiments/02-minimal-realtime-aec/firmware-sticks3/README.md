# M5StickS3 sprite proof

This is deliberately a thin board port:

- `face_sprite_sheet.c` is compiled directly from the shared C/WASM runtime;
- the 40×30 atlas is generated by `tools/sprite-pipeline`;
- this directory owns only M5Unified setup, buttons, microphone capture, and
  the 240×135 RGB565 display flush.

Controls:

- hold Button A: push-to-talk capture and listening expression;
- click Button B: cycle expression banks;
- hold Button B: deterministic speaking/viseme preview.

Build and flash:

```sh
cd ../tools/sprite-pipeline
python3 -B avatar_pipeline.py build \
  --character characters/gameboy-bot/avatar.json

cd ../../firmware-sticks3
source ~/esp/esp-idf/export.sh
idf.py build
python -m esptool --port /dev/cu.usbmodem2101 read_mac
idf.py -p /dev/cu.usbmodem2101 flash monitor
```
